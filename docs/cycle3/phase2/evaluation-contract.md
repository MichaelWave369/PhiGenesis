# Frozen internal Phase II evaluation contract

Version `phase2-internal-evaluation/v1`. Freeze before comparative runs.
All tasks are internal or previously authored synthetic fixtures. No external
held-out corpus or independently administered evaluator was supplied.

1. Native memory: use the unchanged PhiMemory9 R0.5 36-query benchmark and its
   already frozen lexical/ancestry/sparse/sparse-history thresholds. Report every
   method and subgroup, negative queries and abstentions; do not tune thresholds.
   Do not compare these text ranks numerically with Φ030's class predictions.
   The adapter's temporal/context/availability tests are admissibility checks,
   not a new retrieval superiority benchmark.
2. Context: report supplied context, explicit context switch, unknown observation
   time and delayed admission as distinct contracts. An inferred/noisy-context
   learning experiment remains PROPOSED; do not call supplied tags inferred.
3. Source-cache overhead: nine paired samples, alternating full-first/cached-first
   order. Hash the identical files/bytes with both paths; assert exact manifest,
   byte and file-count equality. Report all elapsed samples, median and range.
   The change may reduce inventory subprocess cost but cannot reduce covered
   bytes. A median improvement is a local measurement, not a general speed claim.
4. Relational data: deterministic NEST/REVERSE/RECALL/COMPOSE contracts, exact
   parent reconstruction, native syntax/address mapping and all refusal cases.
   No evolutionary accuracy, topology superiority, or Fibonacci advantage is
   asserted. Matched-budget mutation/random/exhaustive search and topology
   cohorts remain PROPOSED until a separate meaningful task is frozen.
5. Continuity: fresh challenge proof, strict prefix binding, disagreement,
   revocation, actual process interruption and known coordinated rollback.
   The latter must be reported as a negative trust result, never hidden by green tests.

Report success, refusal, latency/counters, recovery behavior and negative results
at their actual scope. Adaptation latency/accuracy across independent seeds are
BLOCKED where no comparable developmental task was executed. No post-hoc changes
to these criteria may be used to label a failing result as passed.
