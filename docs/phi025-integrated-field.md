# Φ025 — Integrated Evolutionary Field (advisory bridge)

Convergence pilot, not a production release. Reuses unchanged Φ023 operator/evaluator and Φ024 witness CLIs. The new planner has no key input and cannot write or sign journal events. Explicit trusted operator and witness commands remain required. It reproduces simplified mechanisms inspired by Φ017–021, not imports of those standalone benchmark algorithms or external repo adapters.

## Lifecycle and bounds

Read operator and witness views in separate processes; refuse mismatched heads/states, pending work, exhausted attempts. Observations are seeded synthetic labeled memory (24/context), probes and separate confirmation (12/context); aligned and shifted axes. Compare current/fixed to flag drift; rank up to three recent ancestors, compose same-index best donor pockets, factorized local search and optional three independently calibrated simulated peers. Deduplicate candidates; full probe scores select winner, independent confirmation requires +2 correct and no per-context regression vs incumbent/fixed. Alarm is diagnostic, not a trigger to skip search. Peer suggestions are plain in-process records, not authenticated network transfer; peer-derived proposals use existing learn type, not peer provenance in journal. Proposal is only advisory JSON. Bounds: 18 existing attempts, 19 lineage nodes, max 16,000 target and 4,320 source comparisons per planning call; actual comparison counters returned. Costs of probe caching and peer calibration included; no wall time or label-acquisition cost. Planner calls are not reserved in the durable journal; full cost accounting across restarts is NOT yet achieved. Existing evaluator reserves 1,458 comparisons per admitted proposal. The two budgets must not be conflated. No autonomous retries or promotions.

Pure authoring runtime: 71 assertions passed. Deliberately selected seed 1 exercises a positive aligned proposal [8,0,8], then shifted proposal [0,8,0] (tested in authoring runtime). Node harness stages each proposal, receipt and explicit operator decision through Φ023 and witnesses each transition through Φ024, tests refusal on unsynchronized and pending state, rejects a stale operator anchor. The fixed Φ023 evaluation fixture accepts the aligned proposal and is expected to reject the shifted one. This deliberately exposes the mismatch between adaptive planner evidence and static governance evaluation; not a claim of drift recovery in integrated operation. No automatic signing by planner. Integration harness uses generated keys under one OS account and scripted decisions. Witness log suffix rollback remains possible; no independent key custody or protected monotonic pin. No live Agentora, Altermath, PhiOS, or Pocket Mesh integration. No independent scientific benchmark or performance claim. CI must verify subprocess, persistence, signatures and lifecycle separately.
