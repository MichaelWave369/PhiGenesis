# Φ028 — Unified attempted-work accounting (pilot)

New wrapper over Φ027 provenance, Φ026 context evaluator and Φ025 planner, inspired by RC2's reserve/result journal. Prior versions unchanged. No production promotion.

Planning reservation binds exact wrapper prefix, context, seed, policy, planner source SHA-256 and maximum comparison budget (16,000 local; 20,320 hybrid). Durable start marker precedes planning. Discovery must match reserved seed/policy and pass unchanged Φ027 deterministic verification. Unresolved reservations close only by explicit operator abandonment; a started reservation is uncertain, not measured work. No automatic retry. Maximum 18 planning reservations and 180 events (including previous protocol limits). Evaluation submission already reserves 2,592 comparisons; new eval-start marker required before admitting receipt. Decision without receipt closes as unused if not started, uncertain otherwise. All events preserve original context and proposal signatures. The ledger separates reserved, completed actual comparisons, uncertain upper-bound reservation, unused remainder and open unstarted reserve. Conservation checked on every replay. Started unresolved reservation is counted uncertain even before explicit abandonment. Does not claim actual uncertain compute, acquisition cost, wall time, replay verification cost or exactly-once external effects. Work orchestration is a trusted harness; it does not prevent direct use of older CLIs or unrecorded computation.

Journal uses signed domain-separated operator records, bound to session, four distinct key fingerprints and planner artifact digest; sequence and prior hash verified. Single trusted writer, no-replace hard-link publication after file fsync, directory fsync before return; unreferenced temp ignored. No external protected latest head, so suffix deletion can roll back. No independent OS custody, concurrency guarantee, physical power-loss qualification, network or PhiOS integration. Test host possesses all keys. Existing Φ024 witness not migrated. Journal replay reruns planner evidence and may be expensive; verification comparisons excluded from ledger. Artifact binding covers planner module only, not entire runtime dependency tree.
