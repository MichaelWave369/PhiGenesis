# Φ009 — Constructive discovery

Generate canonical products of eight bipolar numerical inputs to degree four (163 features including intercept); greedily select by residual correlation and refit with least squares. Select a prefix using validation MSE + 0.003 per nonconstant term, with a cap of 12 terms. Flag if validation MSE exceeds 0.25. Compare against identical sparse search with degree ≤2, dense ridge using the same degree-four library, and a training-mean constant. No LLM, network or arbitrary code execution.

360 worlds, 90 disjoint seeds per regime; 112 noisy training examples, 48 noisy validation examples, 96 clean held-out targets per world. Oracle uses integer parity rather than recursive feature construction. Normalization uses training observations only. Hidden supports are never used for fitting, selection or rejection.

Results: 180/180 reachable worlds recover exact support, with three nonconstant terms each. Higher-order mean normalized test MSE: 0.0000941456 generated sparse, 0.6911094 quadratic sparse, 0.5907710 dense ridge, 1.0334028 constant. Low-degree worlds: both sparse methods attain 0.0000898954. All 90 unreachable high-degree worlds and all 90 independent random-target worlds flagged; no false rejections among the 180 reachable worlds. In unreachable and random worlds generated sparse is worse than constant on mean test MSE. Flags do not implement fallback. Six local tests passed.

## Limits

The grammar, feature library, maximum degree, greedy search, scoring penalty and rejection threshold are externally specified, not independently invented. The algorithm is a form of sparse regression/orthogonal matching pursuit with a polynomial feature dictionary, not a novel mathematical method. The generator deliberately favors sparse parity polynomials. Feature generation enumerates the entire bounded library rather than adaptively inventing operators. The test distinguishes in-library from deliberately difficult out-of-library targets, not arbitrary unknown environments. No equal-compute benchmark or independently calibrated rejection threshold. No claim of sentience, general intelligence or open-ended learning. Next stage is a shared runtime with persistent evidence, bounded experiments, explicit uncertainty and independently reviewed validation.
