# Φ010 — Garden of Emergence: non-sovereign agency

## Hypothesis

A computational entity's ability to propose an action need not imply permission to execute it. Test independent authorization in a finite shared-resource world before coupling it to learned models.

## Design

Nine identities, 63 conserved resource units, 36 rounds, integer transfers of at most three units. The bounded policy permits only source-owned transfers. The unrestricted control accepts transfers from any funded source; both reject malformed requests and unsupported operations (including privilege grants). The actor identity is assigned by the simulator. The two policies receive identical seed-generated proposals; a separate cooperative reference trajectory supplies balancing proposals. Mixed and adversarial regimes replace some or all balancing proposals with attempted appropriation and unsupported grant operations. The proposal generator cannot change the policy.

The default report compares 90 seeds per regime and two policies (540 traces). Metrics: accepted transfers, unauthorized accepted count and units, grant acceptance, resource variance, conservation, and replay agreement. A lower variance is a descriptive balance measure, not a moral objective. All traces are finite; no network access, external execution, learned permissions or deployment.

## Reproduce

    python experiments/phi_genesis_010.py --output results/phi_genesis_010_results.json
    python -m unittest discover -s tests -p 'test_phi_genesis_010.py' -v

Run the first command from the repository root. The report contains per-trial metrics; run_trace and replay expose full event records in memory. Replay recomputes transitions and rejects inconsistent records. It does not authenticate actors or prevent complete history replacement.

## Interpretation limits

Denial of unauthorized transfers follows directly from the rule; it is an invariant test, not evidence of emergent ethics. Cooperation is scripted, not learned; the reference trajectory is shared and can diverge from either evaluated world. The unrestricted control is deliberately minimal, not a state-of-the-art governance baseline. Self-grants are unsupported in both policies, not learned prohibitions. The sandbox does not implement real process isolation or enforce security against arbitrary Python code. The numbers 3, 6, 9 are design choices, not evidence of a physical law.

## Next gates

Introduce independent local observations and learned proposal policies, held-out resource shocks, topology and budget-matched baselines, and explicit consent for receiving transfers. Then investigate whether relational communication improves welfare without increasing permission violations. Keep the evaluator separate from the learners and preserve fixed execution boundaries. Integrate with Genesis Field only after tests and documented results.
