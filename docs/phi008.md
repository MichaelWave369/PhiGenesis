# Φ008 — Bounded architecture selection

Run with Python and NumPy:

    python experiments/phi_genesis_008.py --output results/phi_genesis_008_results.json
    python -m unittest discover -s tests -v

360 synthetic worlds (90 seed values reused across four families), each containing all 256 eight-bit inputs. 64 noisy training observations, 32 noisy validation observations, 160 clean held-out targets. Three externally designed candidate feature families: linear (9 coefficients), quadratic (37), lookup over four fixed bits (16). All fitted with ridge regression. The selector minimizes validation MSE plus 0.001 times coefficient count. A fixed threshold of 0.35 flags poor fit. Training-only normalization avoids using held-out target statistics. The test set is not involved in selection or rejection.

## Results

Correct family selection 270/270 in-family worlds; one rejected despite correct selection. All 90 out-of-family cubic-plus-lookup worlds flagged. Mean normalized test MSE across familiar worlds: linear 0.638917, quadratic 0.353596, lookup 0.575889, selected 0.014757, constant 1.063417. On novel worlds selected MSE 1.196439, worse than constant 1.048651. Rejection is a diagnostic flag; no fallback is executed. Five local tests passed. Results are reproducible with the seeded script; full per-world records emitted by --output.

## Limitations

The world generator shares feature families with the learner; the deliberately distinct novel regime is not a general OOD test. The penalty, threshold, bit positions and features are externally supplied, not discovered; thresholds are not independently calibrated. Initial exploratory version normalized using all targets; final version corrected this before reporting. No frozen external benchmark exists, so this is exploratory evidence rather than an unbiased confirmatory result. Fixed alternatives fit individual models rather than optimizing an architecture across tasks. Three candidate fits cost more compute than one; no runtime or equal-FLOP claim. No architecture mutation, arbitrary code execution, deployment or general intelligence. Next: independently generated task families, a bounded abstention/fallback policy and resource-normalized evaluation.
