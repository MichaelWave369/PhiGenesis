# Φ007 — Executable relations

Run from the root (Python 3.10+, standard library only):

    python experiments/phi_genesis_007.py --output results/phi_genesis_007_results.json
    python -m unittest discover -s tests -v

A seeded finite simulator generates three affine maps over the prime field F31 and an invertible affine coordinate bridge. The sender infers each map from two observed pairs; the receiver infers the bridge from two paired observations. Nine predetermined-length randomized sequences of 2–12 primitives are composed into executable affine coefficient pairs. A recipient translates a composite by conjugation B∘F∘B⁻¹. Compare with a cold learner using two direct observations per composite, and an unaligned transfer control. All evaluate the remaining 29 inputs. No LLM, network, arbitrary code execution or system changes. The operations are bounded data, not transferred scripts.

## Results

90 seeded environments, 810 composites and 23,490 held-out input/composite pairs. Composed, translated and cold predictions each 23,490/23,490; unaligned 812/23,490 (3.4568%). Learning observations: six sender pairs plus two bridge pairs versus 18 cold composite pairs. This is an observation-count comparison only, not a bandwidth, runtime or compute comparison. A stronger cold baseline that learns shared primitives locally may close the gap. The two calibration anchors are reused; test inputs are all remaining elements. The simulator and learner use the same affine operation algebra, so the result is expected, not evidence of a novel algebra. Sequence generation is external; the learner does not choose the sequence, invent its instruction set, or discover the hypothesis family. The receiver is a separate numerical coordinate model, not a persistent autonomous being.

## Failure probes

A quadratic perturbation that agrees on both anchors is detected by one held-out probe in 810/810 cases (by construction). A unit slope corruption is detected in 792/810 cases (97.7778%); 18 false negatives occur when the probe is zero. Single-probe agreement is not a proof of correctness. Validation cost is not included in the sample-cost comparison. Future work: randomized unknown representation families, stronger cold baselines, noisy observations, multiple probes, and independently implemented oracle/evaluator.

Seven local regression tests pass. Full seeded results are regenerable; summary JSON records the measured counts. No claims of sentience or general intelligence.
