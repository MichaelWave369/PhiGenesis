## Earlier session concepts (not independently rerun here)
- ΦGnosis: partial observability, observation/actual/model separation, evidence status, local reference frames, horizon ambiguity; 9x9 vs 13x13 induced neighborhoods match through radius 4. Localization requires stated metric and anchors.
- CuriosityCore: entropy reduction with explicit candidate set and instrument costs; avoid surprise-only/noisy-TV reward. The 18-world binary experiment has 9 observable classes and one inaccessible bit. Retain uncertainty at saturation. Prior exploration counts need a retained oracle.
- ΦSymbiosis: provenance-aware evidence union, distinguish transmission from independent measurement, record correlation and uncertainty, permit disagreement. With 3 independent 80%-accurate binary sensors majority accuracy is 89.6%; duplication cannot improve it. Gossip convergence is conditional on delivery, not truth.
- ΦLingua: emergent signals, compositional generalization, cross-agent translation, verified semantic ledger; separate token, denotation and execution.
- ΦLogos: discover operators, equivalences and shortest programs; learned macros are proposals, not executable privileges. LogosVM/Altermath must validate domain, effect, fuel and authority.
- ΦLatent: history, noise, predictive states, reset/replay, observational equivalence. A reproducible reset does not prove universal determinism; a hidden-state model is not physical hidden-variable evidence.
